# IIDT Escala — 10s motion graphic

1080×1920, 30 fps, 300 frames. Black / white / #FFE600 only, one font (Anton), one word on screen at a time.

| Time | Beat |
|---|---|
| 0.0–1.2s | IIDT → ESCALA |
| 1.2–7.2s | DESIGN · BUILD · MEASURE · BILL · SHARE · SKETCH (1s each, tool name under each) |
| 7.2–8.6s | All verbs stack, collapse into ONE FLOW. |
| 8.6–10s | End card: IIDT ESCALA — SCALE FASTER. |

Edit words/colours in `src/data/content.ts`.

```bash
npm install
npm start          # preview in Remotion Studio
npm run render     # -> out/video.mp4
```
